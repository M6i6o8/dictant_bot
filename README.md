# 🇬🇧 Ежедневный диктант английского

Telegram-бот, который каждый день присылает задание на перевод, а через 30 минут — правильный ответ с грамматическим разбором.

## 🚀 Как это работает

| Время (МСК) | Что приходит |
|-------------|--------------|
| **23:00** | 📝 Задание: предложение на английском |
| **00:00** | ✅ Проверка: перевод + разбор грамматики |

## 🤖 Возможности

- **3 AI-провайдера**: Gemini, Cerebras, OpenRouter
- **Умный выбор**: если один провайдер не работает, бот пробует другого
- **База предложений** на случай, если AI недоступен
- **Защита от повторов**: предложения не повторяются
- **Автоматический разбор**, если AI не дал объяснения
- **Работает 24/7** на GitHub Actions

## 🛠 Технологии

- Python 3.11
- GitHub Actions (расписание)
- Google Gemini API
- Cerebras API
- OpenRouter API
- Telegram Bot API

## 🔧 Настройка для своего канала

1. Создай бота у @BotFather
2. Добавь секреты в GitHub:
   - `BOT_TOKEN` — токен бота
   - `CHAT_ID` — ID твоего канала/группы
   - `GEMINI_KEY` — ключ Google Gemini
   - `CEREBRAS_KEY` — ключ Cerebras
   - `OPENROUTER_KEY` — ключ OpenRouter

3. В файле `dictant_bot.py` поменяй настройки времени:
```python
TASK_HOUR_MSK = 23        # Час задания
TASK_MINUTE_MSK = 0       # Минута задания
ANSWER_HOUR_MSK = 0       # Час ответа
ANSWER_MINUTE_MSK = 0     # Минута ответа
.
